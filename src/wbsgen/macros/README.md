# 同梱のマクロ

`vbaProject.bin` は、「WBS スケジュール更新マクロ」(`UpdateWBS`) を含む VBA プロジェクトです。
Web アプリで書き出す Excel に、そのまま組み込みます (`wbsgen.macro`)。

- 実行: Alt+F8 →「UpdateWBS」
- 内容: 「スケジュール」シートの「状態」を基準日 (既定は今日) で再計算し、ガントのバー
  (plan / progress / actual) と今日線 (now-line) を描き直します
- 前提: シート名「スケジュール」「設定」、記入開始行 6、日付見出し `S4`、列 `D F H I K L M Q R`
  (このツールの日単位の書き出しと同じ配置)。週・月単位の書き出しには合いません

添付のマクロ入りブック (`…_WBS_12.xlsm`) の `xl/vbaProject.bin` を、変更せずに取り出したものです。
差し替えるときは、この README のとおりの前提を保ったまま、同じ名前で置き換えてください。
