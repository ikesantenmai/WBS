# wbsgen — WBS ジェネレータ

*[English](README.en.md)*

期間を指定して**空の WBS (ガントチャート用紙)** を Excel で書き出し、
**記入して戻ってきた Excel をガントチャートで表示**します。

添付の WBS ファイル (`DS_WEB…PJ_WBS….xls`) の書式を解析して、
月と週の見出し・配色・列構成をそのまま再現しています。

日本語版と英語版があります。**既定は日本語**です。

```
wbsgen new --start 2026-04-01 --end 2027-03-31 -o 2026年度WBS.xlsx
wbsgen new --start 2026-04-01 --months 12 --lang en -o FY2026.xlsx
wbsgen serve                                    # ブラウザで作る / 見る
```

使い方の流れ:

1. 期間を決めて空の WBS を配る (`wbsgen new`、または画面の「Excel をダウンロード」)
2. 各自が Excel で項目・日付・進捗を記入する
3. 画面の「Excel を読み込む」で開くと、ガントチャートになる
4. 「ガントチャート付きで書き出す」で、バーを描き込んだ Excel を配れる

---

## 出力されるもの

3 シートの Excel を作ります。

- **スケジュール** — 表側の見出しと日程表、記入用の空行 (`S4` で枠固定)
- **担当者一覧** — 指定した担当者名と追記用の空行
- **設定** — 表示期間・単位・稼働曜日・この期間の休日一覧

スケジュールシートの列は元ファイルと同じ構成です。

| 列 | 内容 | | 列 | 内容 |
|----|------|-|----|------|
| B | 大項目 | | K | 実績 終了日 |
| C | 中項目 | | L | 遅れ |
| D | 項番 | | M | 進捗 |
| E | 項目 | | N | 工数 |
| F | 予定 開始日 | | O | 先行 |
| G | 予定 日数 | | Q | 担当 |
| H | 予定 終了日 | | R | 状態 |
| I | 実績 開始日 | | S〜 | 日程表 |
| J | 実績 日数 | | | |

空行には罫線と表示形式 (日付は `m/dd`、日数は `0 日`、進捗は `0%`) を
入れてあるので、Excel を開いてそのまま記入できます。予定欄には色を付けてあります。

### 日程表の見出し

見出しは元ファイルと同じ 2 段構成です。上段はセルを結合せず、
区切りが変わる列にだけ日付を置き、表示形式で「4月」のように見せます
(セルの中身は日付なので、書式を変えれば年も出せます)。

| 表示単位 | 上段 | 下段 |
|---------|------|------|
| 日 | 月 `m"月"` | 日 `d` ＋ 曜日の行 |
| 週 | 月 `m"月"` | 週の開始日 `m/d` |
| 月 | 年 `yyyy"年"` | 月 `m"月"` |

週の列は**開始日から 7 日刻み**で並びます (曜日には合わせません)。
添付ファイルも表示開始日 2026-02-01 が日曜のため 2/1, 2/8, 2/15 … と
日曜始まりで並んでいます。週の区切りを変えたいときは開始日をずらしてください。

日単位では、土曜・日曜・祝日の列に色が付きます。

## 言語

画面右上の切り替えで、日本語と英語を行き来できます。**既定は日本語**で、
選んだ言語はブラウザに憶えます。コマンドでは `--lang en` を付けます。

言語は次のすべてに効きます。

- 画面の文言、日付の見出し (4月 / Apr)、曜日 (月 / Mon)
- 書き出す Excel のシート名 (スケジュール / Schedule)、列見出し、
  表示形式 (`m"月"` / `mmm`)、設定シートの項目名
- エラーメッセージ、コマンドのヘルプと出力

**読み込みは言語を選びません。** 日本語で作ったファイルを英語表示で開くことも、
その逆もできます (見出しの文字で列を探し、両方の言語の書き方を知っているため)。
状態の色分けも「完了 / Done」「実行中 / In progress」のどちらでも効きます。

## コマンド

```
wbsgen new --start YYYY-MM-DD [--end YYYY-MM-DD | --period-days N | --months N]
           [-o out.xlsx] [--unit day|week|month] [--rows N] [--title 名前]
           [--member 担当] [--workdays 月,火,水,木,金] [--holiday YYYY-MM-DD]
           [--no-jp-holidays] [--lang ja|en]
wbsgen serve [--host 127.0.0.1] [--port 8000] [--reload]
```

`serve` の待ち受け先は環境変数 `HOST` / `PORT` でも指定できます。
`PORT` があるときはホストの既定が `0.0.0.0` になります。

| オプション | 説明 |
|-----------|------|
| `--start` | 開始日 (必須) |
| `--end` / `--period-days` / `--months` | 期間の指定 (既定は 12 か月) |
| `--unit` | 日程表の単位 (既定 `week`) |
| `--rows` | 記入用の空行数 (既定 40) |
| `--title` | プロジェクト名 (既定は「YYYY年 スケジュール」) |
| `--member` | 担当者一覧に載せる名前 (複数指定可) |
| `--workdays` | 稼働曜日 (既定 `mon,tue,wed,thu,fri`。`月,火,…` でも可) |
| `--holiday` | 休業日を追加する (複数指定可) |
| `--no-jp-holidays` | 日本の祝日を休日として扱わない |
| `--lang` | 表示言語 `ja` / `en` (既定 `ja`) |

```bash
# 2026 年度 (週表示・空行 40 行)
wbsgen new --start 2026-04-01 --end 2027-03-31 -o 2026年度WBS.xlsx

# 上期を日単位で、空行 80 行
wbsgen new --start 2026-04-01 --months 6 --unit day --rows 80 -o 上期WBS.xlsx

# 土曜も稼働、年末年始を休業日にする
wbsgen new --start 2026-04-01 --workdays 月,火,水,木,金,土 \
           --holiday 2026-12-30 --holiday 2026-12-31 -o wbs.xlsx
```

### 空の WBS を作る

左に期間・用紙・稼働日の指定、右に**実際の Excel と同じ列・同じ見出し**の
プレビューが出ます。日程表の組み立てはコマンドとまったく同じコードを通るので、
画面で確かめてからダウンロードできます。

### 処理中の表示

読み込みと書き出しには少し時間がかかるので、その間は上部に何をしているかを
出します (「sbi.xlsx を読み込んでいます…」「ガントチャート付きの Excel を
作っています…」)。処理中はボタンを押せないようにして、二重に走らないように
します。

### スマートフォンで使う

画面の幅に合わせて並べ方が変わります。**同じ URL のまま**で、アプリを入れる
必要はありません。

- **幅 760px 以下** (縦向きのスマートフォン): 指定フォームと日程表を横に
  並べられないので、上の「**指定 / プレビュー**」タブで切り替えて使います。
  ボタンは指で押せる大きさにし、入力欄は iOS が勝手に拡大しない字の大きさに
  します。
- **幅 900px 以下** (横向きのスマートフォンや小さな窓): 表を全部出すと日程表が
  画面に入らないので、道具立てに「**列**」の選択が出ます。

| 列 | 出るもの |
|----|---------|
| **項目のみ** (狭い画面の既定) | 項目名だけ。項目名は左に貼り付いたまま、日程表を横になぞって見られます |
| **主要な列** | 項目・予定・実績の日付・進捗・状態 |
| **すべて** | Excel と同じ 16 列 |

広い画面ではこれまでどおり、指定フォームと表を横に並べ、列も全部出します。

### 記入済みの Excel をガントチャートで見る

「Excel を読み込む」に、このツールで作った WBS に記入したファイルを渡すと、
表とガントチャートを並べて表示します。

- **予定バー**と**実績バー**を上下に並べ、担当ごとに色を変えます
- 進捗を書いてあれば、予定バーの中に塗って示します
- 実績が完了していないバーは半透明にします
- **現在日**に赤い破線を引きます
- 状態 (完了 / 実行中 / 遅れ n 日 …) は元ファイルと同じ配色で表示します
- バーにマウスを載せると、予定・実績・進捗・担当・状態が出ます
- **表示単位**を日 / 週 / 月に切り替えて、同じ内容を見比べられます

読み取りは見出しの文字で列を探すので、列を足したり順を入れ替えたファイルでも
読めます。期間・稼働曜日・休日は「設定」シートから、担当者は「担当者一覧」から
読みます。

手書きの表を想定して、次のような書き方も受け付けます。

- 「無し」を表す記号 (`-` `ー` `―` `未` `未定` `なし` `N/A` など) は空として扱う
- 全角の数字と記号 (`８０％` `２０２６/４/１０`) は半角に直して読む
- 日付は `2026-04-10` `2026/4/10` `2026.4.10` `2026年4月10日` `4/10`
- 書式が「標準」のままで数値になっている日付 (シリアル値) も日付として読む
- 日数は `10` `10日` `10 日` `10 days` `10d`
- 進捗は `0.8` `80%` `80`

**読み込んだときにあったシートは、すべて書き出しに残ります。**
書き出しは新しいファイルを作るのではなく、**元のファイルを土台にして、
同じ名前で作り直すシートだけを差し替えます**。

| シート | 書き出しでの扱い |
|--------|-----------------|
| スケジュール / 担当者一覧 / 設定 | 同じ名前で作り直す |
| 要員稼働チェック_◯月 (このツールが作る月ぶん) | 同じ名前で作り直す |
| それ以外すべて | **手を触れずにそのまま残す** |

「それ以外」には、メモ・課題管理・表紙などのほか、日程表の名前を変えてある
シート、計画の範囲外の月の手作りの稼働チェック、隠しシートも含みます。
中身は読まずに置いておくので、グラフ・画像・条件付き書式・入力規則・
オートフィルタ・コメント・印刷範囲・シートの色まで、そのまま書き出されます。
シートの並び順も元のままです (日程表が 1 枚目でなくても、ガントチャートの
図形はそのシートに入ります)。

**日程表のシート名を変えてあっても読めます。** 決まった名前で見つからなければ、
「項目」の列があるシートを上から探します。

**項目名の字下げはそのまま残します。** 「　WEB口座開設システム」のように
行頭の空白 (全角・半角) で階層を表す書き方があるため、前後の空白を落とさずに
読み、画面にも書き出す Excel にも同じまま出します。空白だけのセルは、
これまでどおり空として扱います。

**セルが縦に結合されていても読めます。** Excel は結合セルの値を左上にしか
持ちませんが、画面では範囲すべてに表示されるので、下の行からも同じ値として
読みます (日付や大項目を縦に結合してある表のため)。

**読めないセルがあっても行は捨てません。** その項目だけ空にして、
どの行のどの列かを画面に出します (1 か所の書き間違いで行がまるごと
消えないようにするため)。

**空に見える理由も知らせます。** 記入したはずの日付や進捗が反映されない
ときは、次の 2 つが原因のことがあります。どちらも読み込み時に画面へ
出します。

- **数式の計算結果がファイルに入っていない。** Excel は数式と一緒に
  計算結果も保存しますが、スクリプトなどで作られたファイルには入って
  いません。その場合セルは空として読まれるので、たとえば実績の終了日が
  `=I5+20` のような数式だと完了になりません。**Excel で開いて保存し直す**と
  計算結果が入って読めるようになります。
- **見出しの文字が違っていて列が見つからない。** 「終了」を「おわり」に
  するなど見出しを書き換えると、その列はまるごと空として読まれます。
  見つからなかった列の名前を並べて知らせます。

#### 日数と進捗の決め方

記入内容から次のように決めます。導き出した値は表で薄い字にして、
理由をマウスオーバーで出します。

**日数はセルに書かれた値を使いません。** いったん無かったものとして、
開始日と終了日から数え直して入れます。予定・実績とも同じです。

| 記入されているもの | 決まること |
|---------------------|-----------|
| 予定の開始日と終了日 | **日数はこの 2 つから数え直します** (稼働日、両端を含む) |
| 予定の開始日と日数のみ | 終了日を日数から求めます |
| 予定の開始日が無い | **日数は空にします** (数え直せないため) |
| 実績の開始日と終了日 | **実績日数はこの 2 つから数え直します** |
| 実績の開始日と日数のみ (終了日なし) | **実績日数を空にします**。終了日は求めません |
| 実績の開始日が無い | **実績日数は空にします** |
| 実績の終了日 | **進捗は 100%、状態は「完了」とします**。書かれた進捗・状態より優先します |
| 予定の日付 | **状態と遅れを計算します** (下記) |

終了日を日数から補うのは**予定だけ**です。「開始日 + n 日」は予定の
普通の書き方で、補った終了日から数え直しても同じ日数になります。

**実績では補いません。** 終わっていない作業に実績日数だけが残っているのは
元データの書き間違いなので、その日数は捨てます。ありもしない終了日を作ると、
バーも進捗も実際より進んで見えてしまうためです。この場合、実績の開始日は
そのまま残るので、着手済みであること (状態は「残り n 日」など) は判ります。
実績のバーは、終了日が入るまで描きません。

**実績の終了日が書かれていれば、その行は必ず進捗 100% / 状態「完了」です。**
予定の終了日より後に終わっていても、予定の日付がまったく無くても、書かれた
進捗や状態が違っていても、完了が優先します。項目名が空の行でも、実績が
入っていれば行ごと残します。

実績の終了日が「書かれている」ときだけ 100% にします。実績日数から
**補った**終了日は完了とみなしません (進行中のタスクが勝手に完了になるのを
防ぐため)。同じ理由で、書き出しのときも補った実績終了日はセルに残しません。

終了日を書いたのに完了にならないときは、そのセルが**空として読まれて
います**。読み込み時の注意書きに理由が出るので、そちらをご覧ください
(数式の計算結果が無い / 見出しが違って列が見つからない / セルの中身が
日付として読めない)。

#### 状態

状態は基準日 (既定は今日) から次のように決めて、状態欄に記入します。
判定は上から順に見て、最初に当てはまったものを使います。

| 条件 | 状態 |
|------|------|
| 実績の終了日が記入されている | **完了** |
| 予定開始日を過ぎているのに未着手 / 予定終了日を過ぎているのに未完了 | **遅れ n 日** |
| 着手済み (実績開始日あり) | **残り n 日** — 予定終了日まで |
| 未着手 | **あと n 日** — 予定開始日まで |

日数はいずれも稼働日で数え、その日自身は 0 日とします
(「今日が予定終了日」なら「残り 0 日」)。遅れの日数は**遅れ列**にも
同じ値を入れます。

実績の終了日があれば、予定の日付が無くても完了とします。それ以外で
予定の日付がまったく無い行は判断できないので、書かれた状態をそのまま残します。
状態の配色は添付ファイルと同じです (完了=灰、遅れ=桃、残り=橙、あと=水色)。

### ガントチャート付きで書き出す

表示中の状態のまま「**ガントチャート付きで書き出す**」を押すと、
バーを描き込んだ Excel を書き出します。

- バーは**浮動図形 (DrawingML)** として描くので、週表示・月表示でも
  セルの途中に端が載ります (元の Excel ツールと同じ方式です)
- 予定・実績・進捗のバーと現在日線を、画面と同じ位置に描きます
- 状態の色、大項目・中項目の出し方も元ファイルと同じにします
- 終了日が空だった行には、補った値を書き込みます
- 選んでいる**表示単位で書き出す**ので、日 / 週 / 月を選んでから押してください

書き出したファイルはもう一度読み込めます (内容・期間・集計が一致することを
テストで確かめています)。

### 要員稼働チェック

書き出したファイルには、**月ごとの「要員稼働チェック」シート**が付きます。
「スケジュール」の担当欄に名前がある行の**予定期間**を日別に数えたもので、
誰がいつ空いているか・誰に寄っているかが一目で判ります。

|  | 中身 |
|---|------|
| 行 | 担当欄に出てくる名前 (出た順) |
| 列 | 計画の期間にかかる日すべて。月ごとにシートを分けます |
| 値 | その日に割り当てられているタスクの数 |
| 右の集計 | 稼働日数 / タスク有日数 / 空き日数 / 空き日の内訳 |

色は元の表と同じです (**赤**=稼働日なのにタスク無し（要対応）、**緑**=1〜2 件、
**橙**=3 件以上（過負荷の可能性）、**灰**=非稼働日)。条件付き書式で入れてあるので、
数を書き換えても色は追随します。稼働日かどうかは「設定」シートの稼働曜日と
休業日に従います。

担当欄は「吉田/菊池/虎岩」「長見、本家、池田」「佐々木（高瀬）」のように
1 つのセルに複数書かれていることがあるので、区切って 1 人ずつにします
(敬称の「さん」は落とします)。数えるときは書かれた文字列に名前が**含まれるか**で
判定するので、「佐々木（高瀬）」は佐々木にも高瀬にも数えます。

担当が 1 人も書かれていなければ、このシートは付きません。計画が長い場合は
24 か月ぶんで打ち切ります。

### API

| メソッド | パス | 内容 |
|---------|------|------|
| `GET` | `/api/meta` | 選択肢 (表示単位・曜日・既定値) |
| `POST` | `/api/preview` | 日程表の見出しと寸法を返す |
| `POST` | `/api/build` | Excel を返す |
| `POST` | `/api/import` | 記入済み Excel を読み、ガントチャートの描画モデルを返す |
| `POST` | `/api/export` | 記入済み Excel を読み、ガントチャートを描き込んだ Excel を返す |

リクエストボディは次の形の JSON です。不備があると `422` と日本語の
メッセージが返ります。

```json
{
  "title": "2026年度 スケジュール",
  "start": "2026-04-01",
  "end": "2027-03-31",
  "unit": "week",
  "rows": 40,
  "members": ["設計", "製造"],
  "workdays": ["mon", "tue", "wed", "thu", "fri"],
  "japanese_holidays": true,
  "holidays": ["2026-12-30"]
}
```

`end` の代わりに `period_days` か `months` でも指定できます。

`/api/import` と `/api/export` はファイルを `multipart/form-data` の `file` で
受け取ります。`?unit=day` を付けると、ファイルに書かれた表示単位より優先します。

どのエンドポイントも `?lang=en` で英語になります (省略時は日本語)。
`/api/build` は本文の `language` でも指定できます。

```bash
curl -X POST "http://127.0.0.1:8000/api/export?unit=month" \
     -F file=@記入済みWBS.xlsx -o ガント付き.xlsx
```

## Render にデプロイする

Web Service を作り、次の 2 つを設定します。

| 項目 | 値 |
|------|-----|
| Build Command | `pip install -r requirements.txt` |
| Start Command | `wbsgen serve` |

オプションは要りません。`serve` は環境変数 `PORT` があればそれを使い、
外部から届くように `0.0.0.0` で待ち受けます (Render / Heroku / Cloud Run など、
待ち受けポートを `PORT` で渡す環境向け)。`PORT` が無い手元の環境では
従来どおり `127.0.0.1:8000` です。

明示したい場合は `--host` / `--port`、または環境変数 `HOST` / `PORT` で
上書きできます。

このアプリには認証がありません。デプロイすると URL を知っている人は誰でも
開けるので、社内向けであればアクセス制限を別途かけてください。

### 構成

```
src/wbsgen/
  i18n.py        日本語版・英語版の文言と表示形式
  blank.py       用紙の仕様 (期間・単位・空行数・稼働日・言語)
  timeline.py    日程表の横軸と 2 段見出し
  workcal.py     稼働日判定と日本の祝日
  workload.py    要員稼働チェックの組み立て
  style.py       配色と書式 (添付ファイルから抽出)
  workbook.py    Excel の書き出し
  importer.py    記入済み Excel の読み込み
  chart.py       ガントチャートの描画モデル (画面用)
  drawing.py     DrawingML の生成 (Excel に描くバー)
  inject.py      xlsx への図形パート注入
  cli.py         コマンドライン
  web/
    app.py       FastAPI のエンドポイント
    static/      画面 (index.html / app.js / style.css)
```

Web UI は素の HTML + JavaScript で、ビルド手順も外部 CDN もありません。
